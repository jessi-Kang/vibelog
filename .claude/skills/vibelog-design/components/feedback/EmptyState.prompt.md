EmptyState — 비어 있는 자리를 비워두지 않는다. dashed line-strong 박스(스크린샷 자리표시와 같은 어법) 안에 세 줄: **무엇이 없고 왜** / **언제 채워지는지** / **할 수 있는 한 가지(모노)**. 일러스트·아이콘·이모지 없음. 톤은 담담한 존댓말, 파이프라인 관점("다음 23:00 실행에").
```jsx
<EmptyState title="아직 데브로그가 없습니다" body="이 레포는 6주째 조용합니다. 커밋이 생기면 다음 23:00 실행에 첫 글이 올라옵니다." hint="git commit -m '…' && git push" />
<EmptyState compact title="이 필터에 해당하는 글이 없습니다" />
```
빈 상태 사전(어디에 무엇을 쓰는지)은 readme.md '## Empty states' 참고.
