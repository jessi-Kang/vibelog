상태값과 미공개 프로젝트

두 가지를 정합니다. ① 상태값 넷을 무엇으로 가를지와 멈춘 상태의 이름. ② 숨긴 프로젝트를 방문자에게는 이름 없이 "미공개 프로젝트 A"로, 로그인한 관리자에게는 전부 보이게 하는 모양.

① 상태값 — 무엇으로 가르나

사람이 할 일을 늘리지 않으려고 GitHub Release 하나를 "다 만들었다"는 선언으로 씁니다 (지금도 live 판정에 쓰는 것). 배포 주소가 있다는 것만으로는 "다 만들었다"가 아니어서, 지금 거짓말 탐정은 만드는 중인데 PREVIEW로 나옵니다.

상태뜻판정지금 프로젝트
● LIVE다 만들고 공개Release 있음 + 자기 도메인 주소바이브 로그, 아파트 감별사
● PREVIEW다 만들었지만 공개 전Release 있음 + 자기 도메인 없음 (주소가 없거나 *.vercel.app)없음
● BUILDING계속 만드는 중Release 없음 + 최근 14일 안에 커밋거짓말 탐정, agency, Anchor, 포트폴리오 템플릿
● RESTING만들다 멈춤Release 없음 + 14일 넘게 커밋 없음없음

PREVIEW·LIVE 프로젝트에 다시 커밋이 쌓여도 상태는 그대로입니다 (다 만든 것을 고치는 중). 지금처럼 vibelog.json의 status가 있으면 그게 언제나 이깁니다. 14일은 지금 30일보다 짧게 잡은 값입니다 — 두 주 조용하면 "쉬는 중"으로 보는 편이 실제와 가깝습니다.

멈춘 상태의 이름 — 셋 중 하나

지금 PAUSED는 회색이라 끝난 것처럼 보입니다. 다시 돌아올 프로젝트라는 느낌이 나게, 경고색(주황)·실패색이 아닌 옅은 보라를 씁니다.

● RESTING쉬는 중

잠깐 쉬고 다시 온다는 뜻이 가장 또렷합니다. 추천.

● ON HOLD잠시 멈춤

멈춘 이유가 있다는 느낌. 업무 말투에 가깝습니다.

● SLEEPING잠든 중

가장 가볍고 귀엽습니다. 다른 셋과 말투가 조금 다릅니다.

② 미공개 프로젝트 — 방문자와 관리자가 보는 것

레포에 topic vibelog-hidden을 달면 방문자에게는 이름 대신 "미공개 프로젝트 A"가 카드로 보입니다. 설명·아이콘·주소는 없고 누를 수 없습니다(상세 페이지 없음). 상태와 마지막 활동은 보여서 "뭔가 만들고 있구나"는 알 수 있습니다. 글자 A·B는 한 번 정하면 바뀌지 않습니다(색처럼 projects.json에 적어 둔다). Google로 로그인한 관리자에게는 원래 카드가 그대로 보이고 이름 옆에 숨김 표시가 붙습니다.

만드는 방식 — 미리 알아 둘 것

지금 홈·글·쇼츠 페이지는 미리 만들어 둔 화면을 모두에게 같게 보냅니다(빠르고 서버 비용이 거의 없다). 관리자에게만 다르게 보이려면 페이지가 열린 뒤 브라우저가 "관리자인가"를 물어, 관리자면 숨긴 내용을 따로 받아 끼워 넣습니다. 방문자 화면은 지금처럼 빠르고, 숨긴 글 자체는 로그인 확인을 거쳐야만 내려가므로 페이지 소스에도 남지 않습니다. 숨긴 글의 페이지는 따로 로그인을 확인하는 주소로 열립니다.
