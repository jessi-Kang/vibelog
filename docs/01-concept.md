# 빌드로그 (가칭) — 바이브 코딩 제작기 자동 발행 시스템

핵심 원칙: **커밋이 곧 콘텐츠.** Jessi는 코딩과 승인 탭만 한다.

## 확정된 결정 (2026-09-09)

- 쇼츠 등장 방식: 본인 목소리 클론(ElevenLabs) + 서비스 화면 녹화. 얼굴 노출 없음.
- 언어: 한국어 원본 + 영어 자동 번역 (쇼츠는 KR/EN 두 버전 렌더).
- 블로그 스택: Next.js + Vercel 직접 제작. 이 블로그가 첫 번째 바이브 코딩 프로젝트.
- 승인: 게시물마다 승인 탭 한 번 (텔레그램 봇 미리보기 → ✅). 품질 안정되면 전자동 전환 검토.

## 블로그 구조

1. **프로젝트 카드** — 서비스마다 카드. 상태(아이디어 / 만드는 중 / 배포됨 / 쉬는 중), 라이브 링크, 스택, 최근 활동일. 각 레포의 `project.json`에서 자동 생성.
2. **데브로그 타임라인** — 프로젝트별 "오늘 뭐 했나". 커밋/PR/Claude Code 세션 요약에서 AI가 작성. 형식: 뭘 했다 / 왜 / 삽질 포인트 / 다음 할 것 / 스크린샷.
3. **쇼츠 피드** — 데브로그당 30–45초 세로 영상. 블로그 임베드 + 유튜브 쇼츠 + 인스타 릴스.

## 자동화 파이프라인

```
코딩 (Claude Code)
  └─ Stop 훅 → devlog/YYYY-MM-DD.md 자동 생성 (세션 요약)
       ↓ git push
GitHub Action
  ├─ Claude API → 데브로그 정리, 쇼츠 대본(KR), 영어 번역, 플랫폼별 캡션/해시태그
  ├─ Playwright → 배포 화면 자동 녹화(mp4) + 스크린샷
  ├─ ElevenLabs (클론 보이스) → KR/EN 내레이션
  └─ Remotion → 9:16 템플릿 합성 (화면 + 자막 + 음성)
       ↓
승인 큐 (텔레그램 봇: 글 미리보기 + 영상 → ✅/✏️/❌)
       ↓
  ├─ 블로그 배포 (Vercel)
  ├─ YouTube Data API → 쇼츠 업로드 (KR, EN 각각 또는 EN 자막 버전)
  └─ Instagram Graph API → 릴스 게시 (비즈니스/크리에이터 계정 + 공개 mp4 URL 필요)
```

## 쇼츠 템플릿 3종

- **Ship it** — 배포/릴리즈 날. "오늘 이거 나갔다."
- **오늘의 삽질** — 버그 하나 이야기. 반응 제일 좋은 포맷.
- **Before / After** — 화면 비교 위주, 말 최소.

대본 구조(공통): 훅(3초) → 뭘 만들었나(10초) → 화면 데모(15–20초) → 다음 할 것/CTA(5초).

## 단계별 MVP

- **1단계 (첫 주말)** ✅: Next.js + MDX 블로그, Vercel 배포. 프로젝트 카드 + 데브로그 타임라인. GitHub Action이 커밋 로그 → 데브로그 자동 생성. 이 과정 자체가 첫 데브로그.
- **2단계** ✅: 쇼츠 생성기. ElevenLabs 보이스 클론 등록 → 대본 → TTS → Remotion 렌더. 업로드는 수동으로 품질 확인.
- **3단계**: 텔레그램 승인 봇 + YouTube/Instagram API 자동 게시. 영어 버전 병행. (시크릿 대기 중)
- **4단계**: 조회수/반응 데이터를 블로그 현황판에 자동 반영.

## 사전 준비물

- ElevenLabs 보이스 클론용 음성 샘플 (Instant는 1–2분, Professional은 30분+).
- Instagram 비즈니스/크리에이터 계정 + Facebook 페이지 연결 (Graph API 요건).
- YouTube Data API OAuth 앱 등록.
- 텔레그램 봇 토큰.

## 연결된 도구 활용

Vercel(배포), Neon(승인 큐·게시 이력 DB), ElevenLabs(TTS/보이스 클론), Notion(선택: 아이디어 백로그).
