소개 글에 붙는 그림 시안

소개 글에 무엇을 보여 줄지 세 가지로 놓았습니다. 화면은 지금 vibelog를 실제로 찍은 것이고, 구조 그림은 지금 글 삽화와 같은 바탕판·글자 크기로 제가 그린 예시입니다.

A

실제 화면

소개 글을 쓰는 날 사이트를 찍어 첫 섹션 아래에 2–3장 붙입니다. 무엇을 만드는지 한눈에 보입니다.

어떤 프로젝트인가

vibelog는 제가 바이브 코딩으로 만드는 프로젝트들의 제작기를 사람 손 없이 올리는 블로그입니다. 매일 밤 각 프로젝트의 커밋(작업 메모)을 읽고, 그날 한 일을 글로 쓰고, 30초짜리 쇼츠 영상까지 만듭니다.

지금까지 만든 것

  • 프로젝트 카드가 모인 홈, 날짜별 데브로그, 쇼츠 목록
  • 밤마다 커밋을 모아 글과 설명 그림을 쓰는 작업
  • 실제 사이트 화면을 녹화해 자막과 목소리를 입히는 쇼츠 제작
B

구조 그림

코드에서 읽은 동작을 지금 글 삽화와 같은 방식으로 그립니다. 화면이 없거나 로그인뿐인 프로젝트(Anchor)도 그릴 수 있습니다.

정해 두는 것
  • 화면은 소개 글을 쓰는 밤에 녹화기와 같은 도구로 찍습니다. 주소창은 찍히지 않아 live 전 주소가 드러나지 않습니다.
  • 로그인 없이 볼 수 있는 화면만 찍습니다. 로그인 화면 하나뿐이면 화면은 건너뛰고 그림만 붙습니다.
  • 화면 이미지는 레포에 커밋하지 않고 영상처럼 Blob에 올립니다.
  • 화면은 소개 글을 쓴 날의 모습으로 남습니다. 사진 아래에 "소개 글을 쓴 날의 화면"이라고 적습니다.
  • 구조 그림은 지금 삽화 검증을 그대로 거칩니다. 본문에 없는 숫자는 못 쓰고, 걸리면 그림만 빼고 글은 냅니다.
