쇼츠의 커밋 아이콘을 바꾸기

대본이 "커밋"을 말하면 Tabler의 git-commit 아이콘(세로선 가운데 동그라미)이 나옵니다. 선 하나와 동그라미만 있어 무엇인지 읽히지 않고, 크게 띄우면 금지·오류 표시처럼 보입니다. 지금까지 3편에 4번 나왔습니다 (vibelog 10/13·10/15, apart 10/15). 아래는 1080×1920 화면을 줄인 것입니다 — 위는 아이콘 장면(판 420px·아이콘 220px), 아래는 다이어그램 칸 안의 작은 아이콘(44px)입니다.

git 아이콘이 고르면 같은 세트의 notes로 바꿔 저장합니다. 가장 작은 수정이고 비용이 없습니다. 다만 "글"·"문서"와 모양이 비슷해, 커밋과 글이 한 문장에 같이 나오면 구별이 약합니다.

B 커밋 레일을 코드로 그리기 추천
다이어그램 칸
커밋 메모

쇼츠 첫 장면의 커밋 그래프와 같은 모양입니다 — 가로 선 위 점 셋, 마지막 점만 강조색. 시청자가 영상 첫머리에서 "이게 커밋"이라고 이미 본 그림이라 따로 설명이 필요 없습니다. 코드로 그려서 5테마 색에 저절로 맞고, 두 크기에서 모두 읽히고, 비용이 없습니다. 아래 짧은 번호는 그날의 실제 커밋 번호를 씁니다.

큰 장면에는 어울리지만 다이어그램 칸의 작은 아이콘 자리에는 쓸 수 없어 그쪽은 A나 B가 따로 필요합니다. "커밋"은 손에 잡히는 물건이 아니라 그림으로 그리면 결국 종이·체크 표시가 되어 무엇인지 흐려집니다. 테마마다 그림을 사고, 마음에 드는지 한 장씩 봐야 합니다.
