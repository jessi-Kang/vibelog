어떤 프로젝트인가

vibelog는 제가 바이브 코딩으로 만드는 프로젝트들의 제작기를 사람 손 없이 올리는 블로그입니다. 매일 밤 각 프로젝트의 커밋(작업 메모)을 읽고, 그날 한 일을 글로 쓰고, 30초짜리 쇼츠 영상까지 만듭니다.

누구를 위해, 왜

만드는 과정을 따로 정리할 시간이 없어서 시작했습니다. 커밋 메시지만 제대로 남기면 기록이 저절로 쌓이게 하고, 처음 들어온 사람도 무엇이 어떻게 만들어졌는지 따라올 수 있게 하려는 것입니다.

지금까지 만든 것

  • 프로젝트 카드가 모인 홈, 날짜별 데브로그, 쇼츠 목록
  • 밤마다 커밋을 모아 글과 설명 그림을 쓰는 GitHub Actions 작업
  • 실제 사이트 화면을 녹화해 자막과 목소리를 입히는 쇼츠 제작

다음 할 것

새 프로젝트가 등록되면 이렇게 소개 글부터 쓰게 하는 것입니다.

밤 실행에서 일어나는 일

  1. 소개 글이 없는 프로젝트가 있으면 레포의 코드를 읽습니다. 파일 목록, README, package.json, 화면을 그리는 파일부터 정해진 분량만큼 읽습니다.
  2. 판단할 코드가 아직 없으면 소개 글을 미룹니다. README나 설정 파일뿐이면 AI를 부르지 않고 넘깁니다. 코드가 있어도 무엇을 만드는지 알 수 없다고 AI가 답하면 그날은 쓰지 않습니다. 실행 기록에 이유가 남고, 다음 밤에 다시 봅니다.
  3. 소개 글을 쓴 밤에는 그 프로젝트의 일반 글을 쓰지 않습니다. 그날 커밋은 다음 밤 글에 들어갑니다. 같은 날짜에 글이 둘이면 주소가 겹치기 때문입니다.
  4. 프로젝트 설명은 소개 글과 같은 호출에서 함께 씁니다. AI 호출이 따로 늘지 않습니다.
  5. 소개 글도 일반 글과 같은 안전 검사를 거칩니다. 코드에 들어 있는 주소·키가 글에 옮겨지면 그날 내지 않습니다.
