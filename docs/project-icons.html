정해 두는 것
  • 고른 스타일의 아이콘 이름 목록을 AI에게 주고 그 안에서만 고르게 합니다. 목록에 없는 이름은 버리고 아이콘 없이 둡니다 — 그럴듯한 이름을 지어내 빈칸이 생기지 않게.
  • 아이콘 모양은 고를 때 한 번 받아 projects.json에 적어 둡니다. 화면은 그것을 그리기만 해서, 방문할 때 Iconify에 따로 요청하지 않습니다.
  • 소개 글이 없는 프로젝트는 아이콘이 없습니다. 한 번 정하면 밤마다 바꾸지 않습니다.
  • 프로젝트 페이지 정보 카드에만 둡니다. 홈 카드에 넣을지는 이것을 보고 따로 정합니다.
