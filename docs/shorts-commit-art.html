커밋 장면 그림 — 연필이 놓인 메모

git 아이콘 하나만 뜨던 장면을 이 그림으로 바꿉니다. 다이어그램 칸 안의 작은 git 아이콘과 글자는 그대로입니다. 테마 다섯 개로 실제로 그렸고, 쇼츠 화면에 실제 크기(820px)로 얹었습니다. 밝은 테마는 색 세 가지 중 하나를 고릅니다.

어두운 테마 네 개

terminal
blueprint
signal
highlighter

네 장 모두 메모로 바로 읽힙니다. 다만 terminal·signal·highlighter는 연필과 체크 둘 다 강조색이 들어가, 그림체 규칙(강조색은 한 군데)과 다릅니다. blueprint만 체크 하나에 강조색이 있습니다. 거슬리시면 그 세 장만 다시 그리겠습니다.

밝은 테마 (paper) — 색 세 가지

paper · 지금 색
paper · 흰 면 + 회색 그림자 (추천)
paper · 흰 면 + 옅은 초록 그림자

지금 색은 회색 종이가 회색 바탕에 놓여 칙칙합니다. 흰 면 + 회색 그림자는 종이가 하얗게 떠서 가장 밝고 깔끔하며, 강조색이 체크 한 군데뿐입니다. 흰 면 + 옅은 초록 그림자는 산뜻하지만 글줄까지 초록이 돌고 연필 끝에도 강조색이 들어갑니다.
