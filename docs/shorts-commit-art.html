커밋 장면에 쓸 그림 후보

판 위에 git 아이콘 하나만 뜨던 장면을 이 그림 한 장으로 바꿉니다. 다이어그램 칸 안의 작은 git 아이콘과 글자는 그대로 둡니다. 그림은 지금 쇼츠 그림과 같은 그림체(둥근 평면·강조색 한 군데·투명 배경)로 실제로 만든 것이고, 어두운 테마(terminal)와 밝은 테마(paper)에 실제 크기(820px)로 얹었습니다. 하나를 고르시면 나머지 테마 3개도 같은 그림으로 만들어 고정해 두고, 밤마다 다시 만들지 않습니다.
