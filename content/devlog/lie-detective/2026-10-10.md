## 뭘 했나

용의자의 답변 규칙을 브라우저에서 서버로 옮겼습니다. 게임에서는 사진을 찍고, 그 사진을 들고 용의자 세 명에게 자유롭게 질문합니다. 지난번에 만든 체험판은 HTML 파일 하나로 휴대폰 [[브라우저|크롬처럼 웹사이트를 보는 프로그램]] 안에서 다 돌아갔습니다. 이제는 질문을 하면 [[서버|요청을 받아 답을 만들어 돌려주는 컴퓨터]]가 답합니다. 화면 코드와 서버 코드를 확실히 나누려고 게임 전체를 [[Next.js|화면과 서버 코드를 한 프로젝트에서 나눠 짜는 도구]]로 옮겼습니다.

## 왜

체험판에는 용의자가 언제, 어떻게 거짓말하는지가 브라우저 코드에 그대로 들어 있었습니다. 브라우저 코드는 누구나 '소스 보기'로 열어 볼 수 있습니다. 그래서 추리의 답을 거꾸로 알아낼 수 있었습니다. 이제 브라우저 코드에는 인물 소개만 남기고, 답변 규칙은 서버에만 둡니다. 게임을 [[배포|만든 것을 인터넷에 올려 누구나 쓰게 하는 일]]할 때도 검사를 거칩니다. 사건의 정답이나 AI를 부르는 데 쓰는 [[API 키|외부 서비스를 쓸 때 내는 비밀번호 같은 값]]가 브라우저 코드에 섞였으면 배포가 멈춥니다.

## 삽질 포인트

배포하려는데 [[Vercel|웹사이트를 올려 주는 서비스]]에서 [[빌드|배포 전에 코드를 묶는 단계]]가 오류로 멈췄습니다. 알고 보니 로그인과 저장 기능 코드에 [[역슬래시|키보드의 \ 기호]]가 쓸데없이 하나씩 붙어 있었습니다. 그 역슬래시 때문에 코드가 끝나지 않은 문장처럼 읽혔습니다. 역슬래시를 지우고 빌드를 다시 돌려 확인했습니다.

## What I did

I moved the suspects' answer rules from the browser to the server. In the game, you take photos, then bring them to three suspects and ask them anything. The demo I built last time was a single HTML file that ran entirely inside the phone's [[browser|the app you view websites with, like Chrome]]. Now, when you ask a question, the [[server|the computer that receives requests and sends back answers]] replies. To keep the screen code and the server code clearly apart, I moved the whole game onto [[Next.js|a tool that splits screen and server code in one project]].

## Why

In the demo, the rules for when and how each suspect lies sat right in the browser code. Anyone can open browser code with "view source." So you could work backward to the solution. Now the browser code only has the character introductions, and the answer rules live only on the server. Every time I [[deploy|put the game online so anyone can use it]], there is also a check. If the case's answers or the [[API key|a password-like value for using an outside service]] used to call the AI slipped into the browser code, the deploy stops.

## Rabbit holes

When I tried to deploy, the [[build|the step that bundles the code before deploying]] on [[Vercel|a service that hosts websites]] stopped with an error. It turned out the login and save code each had a stray [[backslash|the \ key on the keyboard]]. That backslash made the code read like a sentence that never ended. I removed the backslashes and ran the build again to confirm.
