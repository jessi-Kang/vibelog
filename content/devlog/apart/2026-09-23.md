## 뭘 했나

매일 밤 아파트 목록을 조금씩 받아오게 했습니다. 부산, 대구, 인천, 경기 순으로 남은 양이 적은 곳부터 채우고, 같은 밤에 가짜 이름도 새로 만들어 넣습니다.

## 왜

자료를 내주는 쪽에서 하루에 5,000건까지만 줍니다. 한 번에 다 받을 수 없으니 매일 밤 나눠 받습니다. 순서를 남은 양이 적은 곳부터로 잡은 이유는, 물량이 가장 많은 경기를 먼저 걸면 몇 주 내내 경기만 받고 나머지 지역은 얇은 채로 남기 때문입니다.

가짜 이름도 같은 밤에 채웁니다. 진짜 목록이 늘어나면, 지어낸 줄 알았던 이름이 실제로 있는 단지로 밝혀져 문제에서 빠집니다. 새로 만들어 넣지 않으면 가짜 문제만 계속 줄어듭니다. 이름을 짓는 방식은 실제 단지 이름을 조각내 배운 것이라, 생김새만 보고는 진짜와 구분되지 않습니다.

## 삽질 포인트

받아온 목록을 그대로 덮어쓰게 두면 큰일 날 뻔했습니다. 문제 풀에는 자동 수집으로는 안 잡히는 단지를 손으로 넣어 둔 것이 있는데, 덮어쓰기로 만들었다면 매일 밤 그것들이 소리 없이 사라집니다. 그래서 통째로 갈아끼우지 않고, 새로 받은 것만 더하는 방식으로 바꿨습니다.

## 다음 할 것

광주와 전남은 목록을 달라고 해도 0건이 돌아옵니다. 이 두 곳은 아직 문제가 한 건도 없어서, 원인부터 찾아야 합니다.

## What I did

The apartment list now gets pulled in a little every night. It fills the thinnest regions first — Busan, Daegu, Incheon, then Gyeonggi — and makes a fresh batch of fake names on the same night.

## Why

The source only hands out 5,000 records a day. There is no way to take it all at once, so it comes in nightly slices. The order starts with whatever has the least left, because Gyeonggi is the biggest pile: put it first and you spend weeks on Gyeonggi alone while everywhere else stays thin.

The fake names get topped up the same night. As the real list grows, names I thought were invented turn out to belong to buildings that actually exist, so they drop out of the quiz. Without new ones, the fake side only shrinks. The names are built from pieces of real building names, so you cannot tell them apart by looks alone.

## Rabbit holes

Overwriting the list each night would have been a quiet disaster. Some buildings were entered by hand because the automatic pull never catches them, and a straight overwrite would erase them every single night. So the nightly run adds to the list instead of replacing it.

## Next up

Gwangju and Jeonnam return zero records no matter how I ask. Neither has a single question yet, so I need to find out why first.
