## 뭘 했나

아파트 이름을 보고 실제로 있는 단지인지 지어낸 이름인지 맞히는 하루 10문제짜리 퀴즈를, 기획 문서부터 실제로 돌아가는 웹사이트까지 하루에 만들었습니다. 화면 시안 3종을 그려 놓고 서류 접수 창구 느낌으로 정했습니다. 전국 누구나 같은 날에 같은 10문제를 받고, 다 풀면 등급이 나오고, 결과를 링크로 공유할 수 있습니다. 정답은 서버만 알고 있어서 화면을 뜯어봐도 미리 볼 수 없습니다.

두 번째 게임도 붙였습니다. 힌트를 보고 섞인 글자 조각에서 실제 단지 이름을 맞춰 조립하는 방식입니다. 어제 문제를 다시 보는 화면, 탭에 뜨는 작은 아이콘도 만들었습니다. 이제 작업한 걸 올리기만 하면 사이트에 자동으로 반영됩니다.

## 왜

같은 게임만 매일 하면 금방 질립니다. 결이 다른 두 번째 게임을 둔 이유입니다. "이 문제, 23%만 맞혔습니다" 같은 전체 정답률이 이 퀴즈의 핵심 재미인데, 기존 방식은 접속한 서버마다 따로 세고 있어서 사실상 전국 정답률이 아니었습니다. 제대로 한 곳에 모이도록 옮겼습니다. 대신 집계가 실패해도 게임은 멈추지 않게 했습니다.

## 삽질 포인트

가짜 이름이 실제 단지와 너무 비슷하면 정답 시비가 나니, 자동으로 걸러 주는 검사를 만들었습니다. 그런데 전혀 닮지 않은 이름끼리 222건이나 경고가 떴습니다. 두 이름이 얼마나 다른지 세는 계산에서, 충분히 다르면 중간에 멈추고 3을 돌려주게 해 뒀는데 하필 3이 "비슷함" 기준 안쪽이었습니다. 빨리 끝내려고 넣은 장치가 가짜 경고를 만든 셈입니다. 멈춤 신호를 기준 밖 숫자로 바꾸니 경고가 0건이 됐습니다.

공유 링크의 미리보기 그림도 한 번 깨졌습니다. 글자와 숫자를 나란히 놓았더니 그림 그리는 쪽이 서로 다른 두 덩어리로 보고 오류를 냈습니다. 하나로 합쳐 해결했습니다.

## 다음 할 것

지금 문제에 쓰인 단지 정보는 샘플입니다. 실제 자료를 받아오는 부분은 만들어 뒀고, 사람이 한 번 검토한 뒤에만 문제로 올라가게 할 생각입니다. "우리 동네 있는데요" 같은 제보가 가장 큰 위험이라서입니다. 보류해 둔 공유 카드 그림도 다시 만들 차례입니다.

## What I did

Today I went from a planning document to a working site in one day. The game shows you an apartment complex name and you guess whether it is real or made up, ten questions a day. I drew three visual directions and settled on one that looks like a paperwork counter. Everyone in the country gets the same ten questions on the same day, gets a grade at the end, and can share the result as a link. The answers live only on the server, so you cannot peek by poking at the page.

I added a second game too: you read a few hints and assemble a real complex name out of scrambled pieces. I also built a screen for revisiting yesterday's questions and a small icon for the browser tab. From now on, whatever I finish goes live automatically.

## Why

One game every day gets old fast, so the second one is deliberately a different kind of thinking. The line "only 23% got this right" is the heart of the fun, but the old setup counted separately on each server, so it was never really a nationwide number. Now it all gathers in one place. If that counting fails, the game keeps running anyway.

## Rabbit holes

Fake names that sit too close to real ones cause arguments, so I wrote a check that flags them. It flagged 222 pairs that look nothing alike. The routine that measures how different two names are stops early when they are clearly far apart, and it returned the number 3 to say so — but 3 happened to fall inside the "too similar" range. The shortcut I added for speed was manufacturing false alarms. Changing that stop signal to a number outside the range brought it down to 0.

The link preview image broke once as well. Putting text and a number side by side made the drawing step read them as two separate blocks and fail. Merging them into one piece fixed it.

## Next up

The complex data in the questions is still sample material. The part that fetches real records exists, but nothing goes into the question pool until a person reviews it — a "that one is in my neighborhood" report is the biggest risk here. The shared result card artwork is also waiting for a redo.
