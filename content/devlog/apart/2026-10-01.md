## 뭘 했나

밤마다 실제 아파트 목록을 조금씩 받아오게 했습니다. 공공 자료를 내려받을 수 있는 양이 하루 5,000건으로 막혀 있어서, 하룻밤에 다 받는 대신 매일 조금씩 나눠 받습니다. 순서는 아직 적게 모인 지역부터입니다. 부산, 대구, 인천, 경기 순입니다. 같은 밤에 가짜 이름도 새로 만들어 넣습니다.

## 왜

단지가 가장 많은 경기를 먼저 넣으면 몇 주 내내 경기만 받습니다. 그동안 다른 지역은 문제로 낼 이름이 얇은 채로 남습니다. 가짜 이름 쪽은 반대로 계속 줄어듭니다. 지어낸 이름인 줄 알았는데 실제로 있는 단지로 확인되면 문제에서 빼야 하기 때문입니다. 실제 목록이 늘수록 가짜가 깎여 나가니, 같은 밤에 새로 채워 넣습니다.

## 삽질 포인트

목록 파일에는 자동으로 받아온 것 말고 손으로 직접 넣은 단지도 섞여 있습니다. 새로 받은 목록으로 파일을 통째로 바꾸면 손으로 넣은 것들이 매일 밤 조용히 사라집니다. 그래서 갈아 끼우지 않고 없는 것만 더하는 방식으로 바꿨습니다.

## 다음 할 것

지역별로 남은 양을 계속 줄여 나갑니다. 광주와 전남은 자료 쪽에서 0건이 돌아와 아직 한 곳도 없는데, 원인을 따로 봐야 합니다.

## What I did

The real apartment list now fills itself in a little every night. The public data source caps downloads at 5,000 records a day, so instead of grabbing everything at once, it takes a slice each night. The order starts with the regions that have the fewest so far: Busan, Daegu, Incheon, then Gyeonggi. On the same nights, new fake names get added too.

## Why

If Gyeonggi went first, it would eat every night for weeks because it has the most complexes. Meanwhile the other regions would stay thin on names to quiz with. Fake names move the other way: they keep shrinking. A name I thought was invented sometimes turns out to belong to a real complex, and then it has to come out of the question pool. The more real names arrive, the more fakes get removed, so new ones are written the same night.

## Rabbit holes

The list file also holds entries I typed in by hand, not just the downloaded ones. Replacing the whole file with each fresh download would quietly erase those every night. So it now adds only what is missing instead of swapping the file out.

## Next up

Keep chipping away at the regions still short on entries. Gwangju and South Jeolla come back with zero records, so that needs a separate look.
