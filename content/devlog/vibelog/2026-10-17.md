## 뭘 했나
공개 전 프로젝트를 이름 없는 카드로 숨길 수 있게 했습니다. 홈에는 제가 만드는 프로젝트마다 카드가 한 장씩 있습니다. 프로젝트를 올릴 때는 [[레포|코드를 모아 두는 저장소]]에 [[topic|GitHub 레포에 다는 꼬리표]] 하나만 달면 됩니다. 이제 숨김용 topic을 하나 더 달면, 방문자에게는 "미공개 프로젝트 A" 같은 카드만 보입니다. 이름과 설명, 글, [[쇼츠|짧은 세로 영상]]는 빠집니다. 카드에는 상태와 무엇으로 만드는지만 남습니다. 제가 Google로 로그인하면 원래대로 다 보입니다. 이 밖에 글 제목 아래 줄에는 모든 글에 똑같이 붙던 "AI 작성" 대신 그 글의 날짜를 적었습니다.

## 왜
아직 공개하고 싶지 않은 프로젝트가 둘 있었습니다. 처음에는 사이트에서 아예 뺐습니다. 그랬더니 방문자는 제가 무언가 만들고 있다는 것조차 알 수 없었습니다. 올리는 것이 topic 하나이니, 숨기고 여는 것도 topic 하나로 맞췄습니다.

## 삽질 포인트
숨기고 나서 보니 숨긴 프로젝트의 이름과 설명, 레포 주소가 방문자 브라우저로 그대로 내려가고 있었습니다. 화면에는 안 보여도 페이지 코드를 열면 읽히는 상태였습니다. 브라우저는 화면을 그리려고 화면 코드와 그 코드가 쓰는 자료를 함께 받아 갑니다. 그런데 화면 코드가 숨긴 것까지 든 전체 프로젝트 목록을 쓰고 있었습니다. 그래서 [[빌드|배포 전에 코드를 묶는 단계]] 직전에 숨긴 것을 뺀 목록을 따로 만들었습니다. 화면은 이제 그 목록만 읽습니다.

## 다음 할 것
숨긴 프로젝트에도 그날 작업을 정리한 글이 밤마다 계속 쌓입니다. 방문자에게 안 보일 뿐입니다. 공개하는 날 topic을 떼면 그동안 쌓인 글까지 한꺼번에 열리는지 보겠습니다.

## 그 밖의 소식
**프로젝트 카드의 상태 표시가 실제 진행에 맞게 바뀌었습니다.** 사이트 주소만 있어도 '다 만든 것'으로 표시돼 아직 만드는 중인 '거짓말 탐정'이라는 프로젝트가 끝난 것처럼 보여서, 이제는 [[GitHub Release|다 만든 버전을 정해 공개하는 GitHub 기능]]를 낸 프로젝트만 다 만든 것으로 칩니다. _커밋 3개_

**쇼츠에 연필이 놓인 메모 그림이 새로 나옵니다.** [[커밋|작업을 한 덩어리씩 저장하는 지점]]을 말하는 장면에 전에는 커밋을 뜻하는 git 아이콘이 세로선과 동그라미만으로 크게 떠서, 무엇인지 안 읽히고 오류 표시처럼 보였습니다. _커밋 10개_

## What I did
Unreleased projects can now hide behind a nameless card. The home page has one card for each project I'm building. To add a project, I just attach one [[topic|a tag you attach to a GitHub repo]] to its [[repo|the storage where a project's code lives]]. Now, if I add one more topic for hiding, visitors only see a card like "Unreleased project A". The name, description, posts and [[shorts|short vertical videos]] are left out. The card keeps only the status and what it's built with. When I sign in with Google, I see everything as usual. I also replaced the "AI-written" label under every post title, which was the same on every post, with that post's date.

## Why
I had two projects I didn't want to show yet. At first I removed them from the site entirely. But then visitors couldn't even tell I was building something. Adding a project takes a single topic, so hiding and revealing one now takes a single topic too.

## Rabbit holes
After hiding them, I found that the hidden projects' names, descriptions and repo addresses were still being sent to visitors' browsers. They weren't on screen, but anyone opening the page code could read them. To draw a page, the browser downloads the screen code along with the data that code uses. And the screen code was using the full project list, hidden ones included. So right before the [[build|the step that bundles the code before deploying]], I now make a separate list without the hidden ones. The screen reads only that list.

## Next up
Hidden projects still get a post summing up each day's work every night. Visitors just can't see them. On the day I remove the topic, I'll check that all the posts piled up so far open at once.

## Other news
**Project cards now show a status that matches real progress.** A card used to be marked "done" as soon as it had a site address, which made a project called Lie Detective look finished while it was still in progress, so now only a project with a [[GitHub Release|a GitHub feature for publishing a finished version]] counts as done. _3 commits_

**Shorts now show a drawing of a note with a pencil.** When a short talked about a [[commit|a point where a chunk of work is saved]], a big git icon standing for commits used to appear, just a vertical line and a circle, and it was hard to read and looked like an error sign. _10 commits_
