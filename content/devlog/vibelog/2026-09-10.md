## 뭘 했나

기준 문서(CLAUDE.md, docs/)를 먼저 넣고 Next.js App Router + Tailwind 뼈대, 콘텐츠 로더, 프로젝트 카드·상세 타임라인·데브로그 피드를 세웠습니다. 이어 collect → generate → run 수집·생성 파이프라인과 cron 워크플로를 붙이고, 쇼츠 파이프라인을 대본·TTS·화면 녹화(1/2)와 Remotion 템플릿·ffmpeg 믹스·오케스트레이터(2/2)로 나눠 구현했습니다. 마지막으로 디자인 핸드오프를 스킬로 설치하고 그 규격대로 블로그 5화면을 재구현했습니다.

## 왜

이 레포의 약속은 "커밋이 곧 콘텐츠"입니다. 화면이 소비할 데이터 형식을 먼저 고정해두면 파이프라인은 그 계약만 맞추면 됩니다. 쇼츠는 자막·음성·장면이 한 시계를 쓰는 결정론적 합성이 핵심이라, 실시간 녹화는 소재로만 쓰고 타이밍은 항상 생성된 음성의 타임스탬프에서 가져옵니다.

## 삽질 포인트

- Actions의 `if:`에서 secrets 컨텍스트를 쓸 수 없어 워크플로 파일 자체가 무효 판정, 모든 실행이 1초 만에 실패했습니다. 잡 레벨 env로 우회했습니다.
- 쇼츠가 안 돈 날은 `public/devlog-shots/`가 없어 `git add`가 pathspec 오류. 데브로그가 커밋되지 못했습니다.
- ElevenLabs Music REST가 문서의 모델명을 거부(422). 고정 트랙을 레포에 박아 API 의존을 없앴습니다.
- 요일 표기가 서버 UTC의 `getDay()`로 하루 밀렸습니다.
- Playwright `recordVideo` 크기가 뷰포트와 다르면 회색 패딩이 생기고, `networkidle`은 서드파티 요청 하나에 수십 초를 기다립니다.

## What I did

Started with the reference docs (CLAUDE.md, docs/), then set up the Next.js App Router + Tailwind skeleton, the content loader, and the project cards, detail timeline, and devlog feed. Next came the collect → generate → run pipeline with a cron workflow, and the shorts pipeline split in two: script/TTS/screen recording (1/2), then the Remotion template, ffmpeg mix, and orchestrator (2/2). Finally I installed the design handoff as a skill and rebuilt the five blog screens to that spec.

## Why

The promise of this repo is "commits are the content." Fixing the data contract the screens consume first means the pipeline only has to match that shape. For shorts, the core is deterministic composition where captions, voice, and scenes share one clock — the live recording is just raw material, and timing always comes from the generated audio's timestamps.

## Rabbit holes

- Actions doesn't allow the secrets context in `if:`, so the workflow file itself was ruled invalid and every run failed in one second. Worked around it with a job-level env.
- On days shorts didn't run, `public/devlog-shots/` didn't exist and `git add` threw a pathspec error, so the generated devlog never got committed.
- The ElevenLabs Music REST endpoint rejected the model id from the docs (422). I committed a fixed track to the repo and dropped the API dependency.
- Day-of-week labels were off by one because of `getDay()` on a UTC server.
- Playwright's `recordVideo` size must match the viewport or you get gray padding, and `networkidle` waits tens of seconds on a single third-party request.
