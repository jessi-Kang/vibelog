## 뭘 했나

새 기능을 기획부터 단계별로 돕는 도구를 들였습니다. 무엇을 만들지 적고, 계획을 세우고, 할 일을 쪼개고, 실제로 만드는 순서까지 불러 쓸 수 있는 명령 10개가 추가됐습니다. 이제 저와 AI가 같은 순서표를 보고 일합니다.

## 왜

같이 일하는 사람이 이 도구를 쓸 수 있는지 물었고, 확인해 보니 됐습니다. 지금까지는 기획 문서를 매번 맨손으로 썼습니다. 정해진 순서가 있으면 빠뜨리는 항목이 줄어듭니다.

기능마다 작업 공간을 새로 갈라 주는 부가 기능은 넣지 않았습니다. 이 프로젝트는 갈라 놓지 않고 곧바로 본줄기에 합치는 방식이라 쓸 자리가 없습니다.

도구가 함께 주는 원칙 문서는 빈 틀로 뒀습니다. 이 프로젝트에는 이미 어느 문서가 더 우선인지 정해 둔 규칙이 있어서, 같은 규칙을 두 곳에 적으면 나중에 서로 어긋납니다.

## 삽질 포인트

설치할 때 기존 파일을 덮어쓸 수 있다고 해서, 먼저 버릴 사본에서 돌려 봤습니다. 실제로 설정 파일 하나가 다시 쓰였습니다. 열어 보니 내용은 똑같고 빈 줄만 빠진 것이었습니다. 바뀔 이유가 없는 변경이라 원래대로 되돌렸습니다.

## 다음 할 것

원칙 문서를 처음 쓰는 날, 기존 규칙 문서를 가리키게 할지 정하겠습니다. 새 도구가 기획 문서를 쌓는 자리가 따로 있어서, 원래 있던 설계 문서와 두 집으로 갈라지지 않게 정리도 필요합니다.

## What I did

Brought in a tool that walks a new feature through planning step by step. It adds 10 commands I can call: write down what to build, make a plan, break it into tasks, and then build it. Now the AI and I follow the same checklist.

## Why

A teammate asked whether this tool would work here, and it does. Until now I wrote planning documents by hand every time. With a fixed order, fewer things get left out.

I skipped the extra part that opens a separate work area for each feature. This project merges straight into the main line instead of splitting off, so there was nowhere to use it.

The principles document that ships with the tool stays empty. The project already has a document that says which rules win, and writing the same rules in two places means they drift apart later.

## Rabbit holes

The install can overwrite existing files, so I ran it on a throwaway copy first. One settings file did get rewritten. On inspection the contents were identical and only blank lines were gone. That change had no reason to exist, so I put the original back.

## Next up

The first time I write the principles document, I will decide whether it should just point at the existing rules. The new tool also keeps its own place for planning documents, so I need to make sure it does not split into two homes with the design document we already have.
